# Integrations and data sync

Join imports by CRM account ID and deduplicate by source event ID (SYNC-01, SYNC-02). Save the import receipt for [onboarding](onboarding.md).

Reconcile source and destination row counts. If a mismatch persists, send the run ID to [support](support.md) (SYNC-03). Use the environment filter in [reporting](reporting.md) (SYNC-04).
