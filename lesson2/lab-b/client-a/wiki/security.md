# Security and data handling

Use synthetic data in the sandbox and keep client records in their approved workspace (SEC-01). Give [reporting](reporting.md) read access and keep [integration](integrations.md) writes separate (SEC-02).

Send a run ID and sanitized error to [support](support.md) (SEC-03). The security review is a distinct sign-off in [onboarding](onboarding.md) (SEC-04).
