# One required homework artifact

Choose **A: a coding-agent pipeline** or **B: an agent inside a product**. If you lack data, use the recorded model-choice starter (development replay), or one of the authored fixture projects. Name the evidence mode accurately.

Use bakeoff on one bounded change. Start with at least 30 labeled pilot cases for the course assignment, with separate tuning/evaluation or a dev-only rejection. Thirty is a starting sample, not a statistical guarantee; inspect important slices and costly failures. Set the actual bar from the workflow.

Submit one decision record plus the tested config and enough sanitized receipts to reconstruct it:

- What counts as correct, who labels it, and the cost of both error directions.
- Baseline/candidate, frozen hypothesis and caps, actual failures, quality/cost/whole-job scorecard.
- One consequential trace with evidence mode; all attempts and unknown costs retained.
- Unchanged gate verdict and separate owner decision. Keeping the incumbent counts.
- One own-workflow next experiment. If actually shipped, a rollback rule and measured follow-up.

A reasoning-only plan is useful but must say unexecuted. A recorded replay is useful but must say replay. Do not present fixture costs or a judge score as production value.

Before sharing: remove secrets, private account/project links, personal/customer text and private repository paths. If redaction changes input/output text, document it; preserve usage/cost/latency numbers and error semantics. Do not upload the instructor's grader, original held-out labels or a full private trace dump.

Optional extension: another model, local model, calibration or judge audit. Keep raw private outputs locally for Workshop 4.
